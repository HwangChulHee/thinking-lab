2. **[연습 워크북 풀기](practice/01-workbook.md)** — 기본·중급·심화 문제를 스스로 해결

## 연습과 실습의 구분

- **연습(Exercise):** 배운 것을 설명하고 직접 푸는 훈련. 워크북에서 진행합니다.
- **실습(Lab):** 예상과 실행 결과를 비교하는 실험. 예제 실행, 관찰, 구현, 변형을 포함합니다.
- **도전(Challenge):** 새로운 문제로 원리를 옮겨 적용해 보는 과제. 워크북에 포함됩니다.
- **복습(Review):** 며칠 뒤 힌트 없이 문제를 다시 풀어 체화 정도를 확인합니다.

원서를 따로 열지 않아도 됩니다. 필요하면 참고 자료로만 활용하세요.

## 실행 환경

[Racket](https://racket-lang.org/)을 설치하고 저장소 루트에서 실행합니다.

```bash
racket sicp/01-procedures/examples/processes.rkt
raco test sicp/01-procedures/exercises/ex01-factorial.rkt
```

`raco test`는 연습 코드에 남아 있는 `TODO`를 구현하기 전까지 실패하는 것이 정상입니다.
