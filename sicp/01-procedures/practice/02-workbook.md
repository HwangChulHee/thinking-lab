# 연습 02 — 공통 계산 구조 찾아내기

**먼저:** [개념 교재 02](../lessons/02-higher-order-procedures.md)를 읽으세요. 아래 문제는 독립적으로 풀 수 있습니다. 정답은 일부러 적지 않았습니다.

## 1. 예측 (기본)

```scheme
(define (inc x) (+ x 1))
(define (cube x) (* x x x))
(sum cube 1 inc 3)
```

교재에서 정의한 `sum`을 사용할 때 결과를 예상하고, `term`과 `next`가 각각 몇 번 호출되는지 추적하세요. 경계값에서 `term`은 호출되지 않는다는 사실도 확인하세요.

## 2. 바꿔 보기 (기본)

1부터 9까지 **홀수의 제곱만** 더하고 싶습니다. 기존 `sum`을 수정하지 않고 `term`, `next`, 시작값과 끝값을 정해 보세요. 예상 결과를 먼저 쓰고 계산하세요.

## 3. 합계에서 곱으로 (중급)

`product`를 직접 작성하고 이를 사용해 1부터 5까지의 곱을 계산하세요. 왜 합계의 기본값이 0이고 곱의 기본값이 1인지 설명하세요.

## 4. 계산 방법까지 매개변수로 (중급)

교재의 `accumulate`를 보지 않고 직접 설계하세요.

요구사항:
- 현재 항목을 계산하는 함수 전달 가능
- 다음 항목으로 이동하는 함수 전달 가능
- 항목들을 합치는 함수 전달 가능
- 처리할 항목이 없을 때 사용할 값 전달 가능

이 함수를 이용해 합계와 곱을 각각 계산하세요.

## 5. 재귀적 과정에서 반복적 과정으로 (심화)

`accumulate`의 계산은 아직 처리되지 않은 `combine` 연산을 뒤로 미룹니다. **결과를 누적하는 반복적 과정**으로 바꿔 보세요.

주의: 합치는 함수가 교환 법칙이나 결합 법칙을 만족하지 않으면 결합 순서에 따라 결과가 달라질 수 있습니다. 원래 구현과 완전히 같은 동작을 요구하려면 어떤 조건을 고려해야 할까요?

## 6. 독립 응용 (도전)

다음 세 계산을 살펴보세요.

- 1부터 n까지 숫자의 합
- 1부터 n까지 숫자의 제곱의 합
- 1부터 n까지 숫자의 세제곱의 합

**공통되는 것과 달라지는 것을 말로 먼저 분류**한 뒤, 중복을 줄이는 함수를 직접 설계하세요. 단순히 코드를 짧게 하는 것보다 새로운 문제에 적용하기 쉬운지가 중요합니다.

## 완료 점검

- [ ] 함수를 **전달**하는 것과 즉시 **호출**하는 것을 설명할 수 있다.
- [ ] 공통 구조와 달라지는 부분을 스스로 찾아냈다.
- [ ] 반복적 과정으로 다시 설계해 보았다.
- [ ] 추상화가 불필요하게 복잡해지는 경우를 한 가지 설명했다.
